# Алгоритмын адал явдал

Бие даасан HTML тоглоом. Энэ хавтсаас terminal нээгээд дараах командыг ажиллуулна:

```powershell
python -m http.server 8000
```

Дараа нь `http://localhost:8000/` хаягийг browser-оор нээнэ үү.

2-р “Шугаман” цэсний таван замын даалгаврыг `1.png`–`5.png` зурагт байгаа байрлал, замаар тоглоно. Эхний даалгаварт камерын хэсэгт гарын дохионы жижиг санамж харагдана. Гараа атгаж удирдлагыг идэвхжүүлээд дээш заахад урагшлах, баруун/зүүн заахад эргэх команд нэмэгдэнэ. Нэг дохио бүртгэгдсэний дараа дараагийн дохионы өмнө гараа дахин атгана; ингэснээр дохиог удаан барихад нэг командаас олон удаа нэмэгдэхгүй. Алгаа нээхэд алгоритм ажиллана. Командуудыг дэлгэцийн товчоор ч үүсгэж болно.

Камерын удирдлагад камерын зөвшөөрөл болон HTTPS эсвэл `localhost` шаардлагатай. Долоовор, эрхий хуруугаа чимхэж товч сонгох болон mouse удирдлага хэвээр ажиллана. MediaPipe Tasks Vision сан болон гарын загварыг CDN-ээс ачаалдаг тул интернэт холболт хэрэгтэй.
